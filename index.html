Biết thư mục nào đang ăn ổ đĩa, rồi dọn an toàn

Disk Map quét thư mục home của bạn, vẽ bản đồ dung lượng và chỉ ra phần dọn được: cache, log, node_modules, file cài đặt, app cũ kèm file sót. Có cả mục dọn file trùng và file lớn trên Google Drive.

Tải Disk Map cho Mac
Bản thử 0.9.2 · 30 MB · Mac chip Apple (M1 trở lên), macOS 13 trở lên · Các bản phát hành

Dọn được gì

Mỗi mục ghi rõ dọn xong thì ảnh hưởng gì. Mục tạo lại được thì xoá hẳn để có chỗ ngay; mục cần cân nhắc thì vào Thùng rác để còn lấy lại.

Bản đồ dung lượng

Thư mục trong home hiện thành các ô theo kích thước. Lần quét sau đánh dấu mục nào vừa phình to.

Dọn sâu

Cache ứng dụng, cache trình duyệt và app Electron, log cũ, Thùng rác. Cache của app đang mở không tự được chọn.

Dự án code

node_modules, thư mục build, target, venv tạo lại được. Thư mục có file git đang theo dõi thì bỏ qua.

File cài đặt và file lớn

File .dmg, .pkg đã cài xong trong Downloads, Desktop; file lớn từ 500 MB trở lên để bạn tự xem trước khi bỏ.

Gỡ ứng dụng

Gỡ app cùng dữ liệu nó để lại trong Application Support, Caches, Preferences, LaunchAgents. Tất cả vào Thùng rác.

Google Drive đang thử

Tìm file trùng, file lớn và Thùng rác trên tài khoản Google, dọn ngay trên đám mây, không cần cài app Google Drive.

Cập nhật app

Liệt kê app có bản mới, kể cả app cài qua Homebrew.

Theo dõi máy

CPU, RAM, GPU, ổ đĩa, mạng, pin và tiến trình đang ngốn tài nguyên. Biểu tượng trên thanh menu cho xem số GB còn trống.

Chạy trên máy bạn

Chi tiết ở trang Quyền riêng tư.

  • Chỉ đo dung lượng thư mục và file. Disk Map không mở, không đọc nội dung file.
  • Không gửi dữ liệu ổ đĩa, tên file hay đường dẫn ra ngoài. Kiểm tra key Pro làm ngay trên máy.
  • Mỗi lần dọn có một hộp xác nhận cho cả lô; mục cần cân nhắc phải tick “đã đọc” mới làm được.
  • Không đụng vào iCloud, Ảnh, thư, khoá đăng nhập hay dữ liệu app sandbox. Danh sách quét quá 30 phút thì phải quét lại mới dọn.
  • Mọi lần dọn ghi vào nhật ký trên máy, xem lại được trong app.

Cài đặt

Bản 0.9 là bản thử, chưa được Apple công chứng (notarize), nên macOS chặn app tải từ mạng về. Gỡ chặn bằng một lệnh trong Terminal, làm một lần sau khi cài.

  1. Mở file Disk-Map.dmg vừa tải, kéo Disk Map vào thư mục Applications.
  2. Mở Terminal (bấm ⌘ + Space, gõ Terminal, Enter), dán lệnh dưới đây rồi Enter: 
    xattr -dr com.apple.quarantine "/Applications/Disk Map.app"
    Lệnh không in gì ra là đã xong.
  3. Mở Disk Map trong Applications như app bình thường. Lần quét đầu mất khoảng một phút, các lần sau nhanh hơn.

Lệnh trên chỉ gỡ cờ “tải từ Internet” mà macOS gắn vào riêng Disk Map, không đổi cài đặt bảo mật của máy. Chỉ chạy lệnh này với file tải từ trang này. Đã thử trên macOS 26, MacBook M4.
